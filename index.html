What I make

Built, shipped, in use.

Each one started as a real problem someone kept running into. None of them tries to do everything, and all of them are built to keep working without anyone tending them.

StackLight

One daily email that reads the status pages and changelogs behind your stack, and marks each change red, yellow, or green so you only stop for the ones that break things.

Welcome Book

One QR code in a holiday apartment answers every guest question, in the guest’s own language, with nothing for the host to maintain.

Maštograd

A parent types their child’s name, sees the personalised set the moment they type it, and the order leaves as a print-ready file.
